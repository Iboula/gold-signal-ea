# Gold Signal AI Backend

## Purpose

This backend validates XAUUSD scalp signals generated by MT5.

Architecture:

MT5 EA -> .NET API -> OpenAI validation -> Telegram -> Dashboard

## Features

- Signal validation
- AI scoring
- Swagger
- Docker-ready structure
- Secure API key handling
- Future PostgreSQL support
- Future Blazor dashboard support

## Environment Variable

Never hardcode secrets.

Windows PowerShell:

$env:OPENAI_API_KEY="your_key"

## Run

cd backend/GoldSignal.Ai.Api

dotnet run

Swagger:

http://localhost:5000/swagger
