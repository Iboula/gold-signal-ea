# Gold Signal AI Backend

## Purpose

This backend validates XAUUSD and BTCUSD scalp signals generated by the MT5 expert advisor.

Architecture:

MT5 EA -> .NET API -> Anthropic Claude validation -> PostgreSQL -> Telegram -> Dashboard

## Features

- Signal validation (Anthropic Claude API)
- AI scoring with institutional SMC/ICT framework
- Swagger
- PostgreSQL persistence
- Docker-ready structure
- Secure API key handling (env vars / .env file)
- Blazor dashboard with live SignalR updates

## Environment Variables

Never hardcode secrets. Use a local `.env` file (already in `.gitignore`) for Docker, or a process-level env var when running with `dotnet run`.

Copy `backend/.env.example` to `backend/.env` and fill in values. Generate the Anthropic key at <https://console.anthropic.com> (section API Keys).

### Windows PowerShell (running with `dotnet run`)

```powershell
$env:ANTHROPIC_API_KEY="sk-ant-api03-..."
$env:Anthropic__Model="claude-haiku-4-5-20251001"
```

### macOS / Linux

```bash
export ANTHROPIC_API_KEY="sk-ant-api03-..."
export Anthropic__Model="claude-haiku-4-5-20251001"
```

### Models available (May 2026)

- `claude-haiku-4-5-20251001` — fast, low cost (~$1/M in, $5/M out). Default. Recommended for per-signal validation.
- `claude-sonnet-4-6` — better reasoning, ~$3/M in, $15/M out. Use if you need more nuanced analysis.
- `claude-opus-4-6` — best reasoning, premium tier.

## Start PostgreSQL

```bash
cd backend

docker compose up -d
```

## Entity Framework Migration

```bash
cd backend/GoldSignal.Ai.Api

dotnet ef migrations add InitialCreate

dotnet ef database update
```

## Run API

```bash
cd backend/GoldSignal.Ai.Api

dotnet run
```
