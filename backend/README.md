# Gold Signal AI Backend

## Purpose

This backend validates XAUUSD scalp signals generated by MT5.

Architecture:

MT5 EA -> .NET API -> OpenAI validation -> PostgreSQL -> Telegram -> Dashboard

## Features

- Signal validation
- AI scoring
- Swagger
- PostgreSQL persistence
- Docker-ready structure
- Secure API key handling
- Future Blazor dashboard support

## Environment Variable

Never hardcode secrets.

Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="your_key"
```

## Start PostgreSQL

```bash
cd backend

docker compose up -d
```

## Entity Framework Migration

```bash
cd backend/GoldSignal.Ai.Api

dotnet ef migrations add InitialCreate

dotnet ef database update
```

## Run API

```bash
cd backend/GoldSignal.Ai.Api

dotnet run
```

## Swagger

```text
http://localhost:5000/swagger
```

## API Endpoints

### Analyze Signal

```text
POST /api/signals/analyze
```

### Recent Signals

